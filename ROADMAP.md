# Roadmap

This roadmap outlines the planned evolution of **OpenGRC Lab**.

## 🟢 Short Term (v0.2.0 - v0.3.0)
- [ ] **Real Authentication**: Support for Auth0, Firebase, and NextAuth.
- [ ] **RBAC**: Implement granular roles (Super Admin, Editor, Reviewer, Learner).
- [ ] **Cloud Media**: Integration with AWS S3 for media uploads.
- [ ] **Enhanced Lab Tasks**: Add "Drag and Drop" and "Code Snippet" task types.
- [ ] **Search & Filter**: Global search for journeys and labs.

## 🟡 Mid Term (v0.4.0 - v0.6.0)
- [ ] **AI Tutor**: Gemini-powered assistant to help learners during labs.
- [ ] **Certificates**: Automated PDF certificate generation upon journey completion.
- [ ] **Analytics Dashboard**: Detailed insights for admins on learner progress.
- [ ] **Multi-language Support**: i18n support for content and UI.
- [ ] **LMS Integration**: LTI support for integration with Moodle/Canvas.

## 🔴 Long Term (v1.0.0+)
- [ ] **Multiplayer Labs**: Collaborative labs for team-based learning.
- [ ] **Content Marketplace**: Allow creators to share/sell GRC lab templates.
- [ ] **Mobile App**: Native iOS/Android app for learning on the go.
- [ ] **Enterprise SSO**: SAML/SCIM support for enterprise deployments.

---

*Note: This roadmap is subject to change based on community feedback and contributions.*
