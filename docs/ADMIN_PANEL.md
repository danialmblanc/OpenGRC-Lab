# Admin Panel Guide

The OpenGRC Lab Admin Panel is a powerful tool for managing learning content.

## Accessing the Admin Panel
1. Log in using the **"Continue as Demo Admin"** button on the landing page.
2. You will be redirected to `/admin`.

## Features

### 1. Dashboard Overview
- View total counts of journeys, labs, and case studies.
- Monitor content health (Published vs Draft).
- Track recent administrative activity.

### 2. Content Library
- List all existing content items.
- Filter by type or status.
- Search by title or category.
- **Actions**: Edit, Duplicate, or Delete content.

### 3. Content Editor (Wizard)
A 3-step wizard for creating/editing content:
- **Step 1: Basic Info**: Title, slug, category, difficulty, and description.
- **Step 2: Interactive Builder**: Add multi-step tasks to labs. Define questions, options, and explanations.
- **Step 3: Media & Resources**: Attach video URLs, transcripts, and thumbnails.

### 4. Media Library
- Manage visual and document assets.
- Support for grid and list views.
- Mock upload functionality for demo purposes.

## Content Workflow
1. **Create**: Start a new content item in the editor.
2. **Draft**: Save progress without making it visible to learners.
3. **Preview**: View the content as a learner would.
4. **Publish**: Set status to "Published" to make it live on the dashboard.
